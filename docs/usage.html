店主モード・客モードの使い方と、値付けの設定方法

起動する

index.html をブラウザで開くだけです。ビルド・サーバー・npm install は不要で、オフラインでも全機能が動きます。

uotarou-demo/index.html  ←  ダブルクリック
データはページを再読み込みすると初期化されます。登録した入荷も予約もその都度まっさらに戻るので、発表前のリハーサルは気にせず操作して構いません。

画面の構成

画面上部のヘッダーは、どちらのモードでも常に表示されます。

店主モード / 客モードタブで表示を切り替えます。同じ画面で店主側と客側の両方を見せられます。
現在時刻スライダー15:00〜20:00 を手で動かします。全カードの価格とカウントダウンが即座に連動し、時間が経つほど値下がりする様子をその場で見せられます。

店主モード

入荷登録

  1. 魚種を選ぶ（アジ・サバ・カマス・イサキ・スルメイカ）。写真アップロードは判定ダミーの演出です。
  2. 数量仕入れ値希望売価を入力する。
  3. 品書きを作るを押すと、店主の一言・調理提案3案・下処理オプションが生成されます。
  4. 生成結果をその場で編集する。編集すると表示が「魚太郎AIが下書きしました」から「魚太郎さんが手を入れました」に変わります。
  5. 値付けの方法を設定し（下記参照）、公開するを押すと客モードに反映されます。
下処理オプションを1つ以上選ぶと公開できます。数量や魚種が未入力のときは、その場で入力箇所を案内します。

予約一覧

客からの取り置きが受け取り時刻順に並びます。予約ごとの尾数と下処理の指示がバッジで表示されます。準備完了で対応済みにでき、未確認の予約はタブに件数バッジが出ます。

値付けの方法

商品ごとに2つの方式から選べます。切り替えるたびに、その日の価格がどう動くかがグラフで確認できます。

時間で値下げ（既定）

従来どおりの固定スケジュールです。3段階で階段状に下がります。

定価15:00〜17:59
18時以降設定した割引率（既定20%）
閉店1時間前19時〜。設定した割引率（既定40%）

売れ行きに合わせる（ダイナミックプライシング）

時間だけでなく在庫の減り方にも連動し、価格が連続的に変わります。「閉店までに一定ペースで捌ける」線を想定とし、そこからのズレで補正します。

  • 想定より売れていなければ → 値下げを早める
  • 想定より売れていれば → 値下げを控える（残りわずかなら据え置き）

調整できるのは次の3つです。

閉店時の最大値引き20:00時点で最大どこまで下げるか（0〜70%）
売れ行きへの反応上の補正をどれだけ強く掛けるか
最低利益率仕入れ値に対する下限。この価格を下回らないように調整されます
価格は10円単位に丸められます。公開前のグラフには「想定どおり売れた場合」「売れ残っている場合」の2本に加え、仕入れ値と下限価格が破線で表示されるので、どこまで下がるかを確認してから公開できます。

客モード

カードの見方

店主の一言店主が仕上げた品書き文
残り数量予約が入るたびに減ります。1回の予約で複数尾を指定できます
現在価格時刻スライダーに連動。値下げ中は定価に取り消し線が付きます
値動きの理由ダイナミック方式のときだけ表示（残りわずかのため据え置き中 売れ行きに合わせて値下げ中）
ミニグラフその日の値動きの予測を1本の線で表示。点が現在位置
この先の価格固定スケジュールは「18:00に¥384（20%引き）になる予定です」、ダイナミック方式は「17:30ごろは¥340前後の見込みです」の形式
予測であることの注記価格の下に常に表示。「この先の価格は予測です。売れ行きによって変わります」

画面上部の固定バーには本日の廃棄予定が表示され、予約が入るたびに減っていきます。

取り置きする

  1. 調理提案を見るをタップして3案を展開する。
  2. 下処理をラジオボタンで選ぶ（そのまま／三枚おろし／内臓処理／下味）。
  3. 数量を選ぶ（1尾から残りの数まで）。選んだ数に応じて合計金額が確認モーダルに出ます。
  4. 受け取り希望時間を30分刻みで選ぶ。
  5. 取り置きするを押し、確認モーダルの内容を確かめて確定する。
価格は予約が成立した時点で固定されます。その後の価格の動きにかかわらず、予約済みの金額のままお渡しします。確認モーダルにもその旨が明示されます。
「待てば安くなる」と受け取られないための配慮。この先の価格はあくまで予測であり、売れ行きによって変わることを、カード上の注記・確認モーダル・ミニグラフの説明の3箇所で明示しています。値下げを待つより早めに予約するほうが確実である、という誘導に揃えています。

発表デモの進め方

  1. 店主モードでアジを登録し、AIが下書きした品書きを見せる。一言を少し書き換えて「魚太郎さんが手を入れました」に変わることを示す。
  2. 値付けを「売れ行きに合わせる」に切り替え、スライダーを動かしてグラフの形が変わることを見せる。下限価格の破線で「原価は割らない」ことを説明する。
  3. 客モードに切り替え、時刻スライダーを15:00から20:00へゆっくり動かして値下がりとカウントダウンを見せる。
  4. 取り置きを1件入れ、廃棄予定の数字が減ることと、価格が固定される確認モーダルを見せる。
  5. 店主モードの予約一覧に戻り、下処理の指示が届いていることを示す。
